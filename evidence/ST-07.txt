RESULT: PARTIAL PASS. The limit works and answers 429 with Retry-After, and a fake X-Forwarded-For
does not get around it (the count is per user). But on Floci the count is per Lambda copy, so the
first 130 requests got no 429 at all. A shared counter (the Upstash store the code supports) is

is set, but Floci does not enforce it.
