How to push it to your repo (school-bus-route-stop)
1. In your local clone: git pull
2. Delete everything in your repo folder except the .git folder.
3. Copy everything from this folder into your repo folder.
4. npm ci && npm test
5. git add -A
6. git status   (check the list: no node_modules, no .env, no token files)
7. git commit -m "Fix Lambda deploy, add evidence, security tests, joint test and k6" && git push

How to put it in the team repo (alibasal1/school-bus-tracker), from YOUR account
1. git fetch origin && git checkout yehia/route-stop
2. git merge origin/main
3. Copy your service into a folder named route-stop/ at the top of the repo
   (everything from this folder, without CHANGES-FROM-ALI.txt if you like).
4. Check that only route-stop/ is changed:
     git diff --name-only origin/main | grep -v "^route-stop/"
   It must print nothing. If it prints files (old skeleton files from your branch), put them back
   the way main has them: git checkout origin/main -- <those paths>
   and delete the ones main does not have: git rm <path>. Then run the check again.
5. git add -A && git commit -m "Add Route & Stop service" && git push
6. On GitHub, open a pull request from yehia/route-stop to main titled
   "Route & Stop service (Yehia)".
